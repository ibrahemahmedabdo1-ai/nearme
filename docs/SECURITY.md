# Security notes
Implemented (tested where noted): scrypt password hashing (N=2^15) [tested]; HS256 access tokens with expiry/tamper/alg-none rejection [tested]; opaque refresh tokens stored as SHA-256, rotation, family revocation on reuse [route unexecuted]; TOTP 2FA mandatory for staff/owner [tested vector]; AES-256-GCM for secrets [tested]; RBAC with owner-only permissions enforced in code and by DB CHECK [tested]; parameterized SQL only; per-IP and per-account rate limiting (in-memory: **replace with Upstash/Redis for multi-instance production**); strict security headers; upload policy checks [tested]; append-only audit log [tested in DB]; session revocation on lockdown.
Not yet done / known gaps: CSRF is N/A for bearer-token APIs but the web delete form should add a CAPTCHA; malware scanning integration; Play Integrity attestation; image moderation; penetration test; dependency audit (`npm audit`, `flutter pub outdated`); no claim of "zero vulnerabilities" can be made without an independent review.
